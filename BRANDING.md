# Branding

`icon.png` is this extension's own icon: the sign `</>` drawn for XML Tools. It is not
a vendor's logo; XML is an open W3C standard and has no product logo to use.

## Source

- Drawn for this extension (2026-11-18) by `tests/make_icon.py`, a short script using only
  the Python standard library: a rounded square in dark teal with the white sign `</>`.
- 128 × 128 PNG.
- SHA-256 of `icon.png`: `ddfb76b933f7782c8c4e1a62946c6559f8f9d77296bc926d3b05763ff24fc817`.

## Use

The icon belongs to this extension and may be used with it. No third-party marks are used.
