# Changelog

## 0.1.0 — 2026-11-18

First release.

- Read: Parse XML to records, Parse large XML to JSONL file (element by element).
- Select: Select with XPath (XPath 1.0, namespace prefixes, variables).
- Build: Build XML from records (elements, attributes, nesting, repeats, CDATA, declaration, encoding).
- Check: Check XML, Validate XML against XSD.
- Transform: Transform XML with XSLT; convert XML to and from JSON, CSV and XLSX.
- Edit: Edit XML by XPath, Merge XML documents, Split XML document.
- Format and compare: Format XML, Canonicalize XML (C14N 1.0, exclusive, 2.0), Compare XML documents.
- Safety: no DTDs or entities, no XInclude, no file or network access from XSLT or XSD, limits on size, depth, elements and time.
